# Dog Breed Identification using MobileNetV2

## Project Overview

This project is a deep learning-based image classification system that identifies the breed of a dog from an input image using Transfer Learning with MobileNetV2.

The model is trained on the Kaggle Dog Breed Identification dataset and can classify images into multiple dog breeds.

---

## Features

- Dog breed prediction from images
- Transfer Learning using MobileNetV2
- Image preprocessing and augmentation
- Model evaluation with accuracy and loss metrics
- Predict breed for new images

---

## Dataset

Dataset: Kaggle Dog Breed Identification

https://www.kaggle.com/competitions/dog-breed-identification
